#  Stranger Things: A Guide to Hawkins

Welcome to my first repository! This project explores the lore, characters, and key elements of the hit Netflix sci-fi series **Stranger Things**.

##  Overview
* **Genre:** Sci-Fi / Horror / Drama
* **Creators:** The Duffer Brothers
* **Setting:** 1980s Indiana, fictional town of Hawkins

> "Friends don't lie." — **Eleven**

###  Main Characters

| Character | Actor | Description |
| :--- | :--- | :--- |
| **Eleven** | Millie Bobby Brown | A girl with psychokinetic and telepathic abilities |
| **Mike Wheeler** | Finn Wolfhard | The loyal leader and strategist of the group |
| **Jim Hopper** | David Harbour | The tough-loving police chief of Hawkins |
| **Dustin Henderson** | Gaten Matarazzo | The tech-savvy, science-loving heart of the team |

###  Favorite Seasons Ranked
1. **Season 1** – A masterclass in mystery, nostalgia, and suspense.
2. **Season 4** – Incredible stakes, cinematic scope, and the introduction of Vecna.
3. **Season 3** – Bright, colorful 80s mall aesthetic with high-energy action.
